# 04 · 多子代理提炼与出书

## 为什么要分片并行

一个人的语料可能几十万字。一次性读完既慢又容易丢细节。
把每人的语料切成若干片，**每片交给一个独立的 subagent**，各自输出固定结构，
最后按节合并——这样既并行，又不会因为上下文过长而退化。

## 统一输出契约（关键）

每个 subagent 必须输出**完全相同的 8 个二级标题**：

```
## 1. 人物定位与关系
## 2. 工作方法与判断标准
## 3. 沟通与指令模式
## 4. 数字口径与红线
## 5. 高频场景与应对
## 6. 可复用句式（原文引用）
## 7. 他会挑的毛病 / 常见错误
## 8. 与本人的协作要点
```

有了固定契约，`wx_skill_merge.py` 才能把 N 个片段按节拼成一份完整文档。

## 提示词要点

给每个 subagent 的 prompt 必须包含：

1. **文件清单**（绝对路径）
2. **只提炼这个人**（"我" = 本人）
3. **固定 8 节标题**
4. 硬约束：
   - 原文引用**逐字准确**并标注日期
   - 不得编造，语料没有的写「（语料未涉及）」
   - 每条结论附至少 1 条原文证据
   - `6 至少 8 条句式，按场景分组
   - 篇幅区间（防止某个片段写成长文）
   - **不要加一级标题**（合并时统一加）
5. **输出方式**：写文件 + 只回一句摘要（避免把全文塞回主会话）

## 合并（wx_skill_merge.py）

- 按 `1..8` 分节抽取
- 同一个人多个片段 → 每节下用「### 片段 N」分隔
- 补上标题和语料规模说明

## 出书（wx_skill_book.py）

- 可选 `--plan sections.json` 按角色分组排序
- 可选 `--preface` 加绪论、`--appendix` 加附录
- 目录自动生成

## PDF（html2pdf_safe.py）

链路：Markdown → HTML（内容自适应表格列宽）→ Edge/Chrome **CDP** 打印。

- 用 `Page.printToPDF`，支持页眉页脚、背景色、页码
- **每个实例用独立 `--user-data-dir` 和随机空闲端口**，否则多个转换会互相抢端口卡死
- 大文档（几百页）需要等页面渲染完再打印（本仓库用 `PDF_WAIT` 环境变量控制，默认 3 秒，
  大文档建议 15 秒以上）

## 规模参考

一个几十人的语料库，大约 50 个片段 → 50 个 subagent → 33 份人物文档 → 一本
近 300 页的合订本。全程可重跑，中间产物（`_parts` / `_merged`）都保留。
